Hi! I built Otto, an open-source (MIT) desktop and mobile app for the OpenCode v2 server.

It sets up a cloud machine (Boat, boxd, E2B or Daytona), runs `opencode serve` there as a systemd service, and gives you a native app for Mac, Windows, Linux and Android. Permission prompts reach your phone, and schedules run as cron jobs on the machine, so agents keep working with the laptop closed. It can also connect to any OpenCode server you already run.
